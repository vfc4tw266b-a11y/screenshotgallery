# Screenshot Gallery (Fabric, Minecraft Java 26.2)

Client-Mod. Taste F6 (Standard) oeffnet eine Galerie mit allen Screenshots aus dem Ordner `screenshots`.
- Raster mit Vorschaubildern (4 gleichzeitig sichtbar), mit dem Mausrad oder Pfeil hoch/runter scrollen
- Klick auf ein Bild: Grossansicht mit Zoom-Animation, unten Knopf "Bild kopieren" (Zwischenablage)
- Pfeil oben links (oder Esc / Backspace): zurueck zur Uebersicht
- Oben rechts: Spielername mit Kopf
- Taste aendern: Optionen > Steuerung > Tastenbelegung > "Screenshot Gallery"

Bauen ohne Programme: Repository auf GitHub anlegen, alle Dateien hochladen (inkl. .github/workflows/build.yml),
unter "Actions" den Bau abwarten und unter "Artifacts" die .jar herunterladen.
